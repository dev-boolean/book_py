Reproducibilidad y bibliografía#

Cómo reproducir todo#

Las tablas del paper (experiments/reproducir_todo.py) se generaron con el entorno de requirements-paper.txt (Python 3.13); el resto, con requirements.txt (Python 3.9).

python -m venv .venv
.venv\Scripts\activate                     # en Linux o macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m ipykernel install --user --name mlc-ml

python -m src.runner full                  # las 140 combinaciones (cerca de una hora)
python -m src.artifacts                    # mejores combinaciones, reentrenamiento y serialización
python -m src.artifacts --original --curso # ALEE, regresión bayesiana, SVR (RBF) y LightGBM
python experiments/reproducir_todo.py      # validación confirmatoria, nueve conjuntos y tablas del paper
python scripts/build_dashboard_data.py     # datos precalculados del dashboard
python -m pytest                           # pruebas
jupyter-book build book/                   # este libro (jupyter-book 0.15.1)
python app.py                              # dashboard local

Elemento

Detalle

Semilla

Una sola semilla global, SEED = 42 en src/config.py, propagada a NumPy, scikit-learn, XGBoost, SMOTE y ADASYN, Optuna y DEAP

Entorno

requirements.txt (todo el proyecto) y requirements-dash.txt (dashboard), con versiones exactas

Validación

Anidada: TimeSeriesSplit de 5 pliegues externos y 3 internos, con 1 mes de separación

Presupuesto

40 evaluaciones de hiperparámetros por pliegue externo y por método

Ejecuciones

140 combinaciones del segundo entregable, 18 reentrenamientos finales, 10 iteraciones de diseño del modelo original y la evaluación de 10 modelos en 9 conjuntos de datos

Dispersión

Todas las métricas se reportan como media ± desviación estándar de los pliegues externos

Pruebas

pytest en cada push con GitHub Actions (.github/workflows/tests.yml)

Datos

data/MLC.xlsx, las series de los ocho países adicionales en data/adicionales/ (scripts/descargar_conjuntos_adicionales.py) y DATA_STATEMENT.md

Código

Repositorio de GitHub (pendiente de publicar)
